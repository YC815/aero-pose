# 風阻姿勢大挑戰 v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 無人值守的攤位遊戲：深度相機（今天先用 webcam）抓玩家上半身 → 套到標準 3D 騎士 → 算正面迎風面積 → 排行榜。

**Architecture:** 後端 Python（uv、FastAPI）負責相機、MediaPipe 骨架、選人、濾波，透過 WebSocket 推世界座標骨架；前端 Vite + TS + Three.js 負責 retarget、騎士、面積光柵化、遊戲狀態機和 UI。spec 在 `docs/superpowers/specs/2026-10-15-aero-pose-v1-design.md`，**每個 task 實作前都要先讀 spec**。

**Tech Stack:** Python 3.12、uv、FastAPI、uvicorn、mediapipe 1.1.x（只有 Tasks API）、opencv-python 5、numpy 2、boto3、pytest；TypeScript 6、Vite 8、three 0.186、lil-gui、qrcode、vitest 5、pnpm。

## Task 1: 後端幾何與 Pipeline

**Files:**
- Create: `backend/src/aero/lift3d.py`、`tilt.py`、`selector.py`、`filter.py`、`pipeline.py`、`preview.py`
- Test: `backend/tests/test_lift3d.py`、`test_tilt.py`、`test_selector.py`、`test_filter.py`、`test_pipeline.py`、`test_preview.py`

**Interfaces:**
- Consumes：`aero.types`（`Frame`、`Intrinsics`、`PersonPose`、`StepResult`、`JOINTS`）、`aero.config.Settings`、`aero.sources.base.FrameSource`
- Produces：

```python
# tilt.py
def cam_to_world(points: dict[str, np.ndarray], camera_height_m: float, camera_pitch_deg: float) -> dict[str, np.ndarray]
# flipY: (x, y, z) -> (x, -y, z)；再繞 x 軸轉 θ=pitch（下俯為正）：
# y' = y·cosθ − z·sinθ，z' = y·sinθ + z·cosθ；最後 y' += camera_height_m
# 檢查：θ=30° 時，相機座標 (0,0,1) → 世界 (0, h − 0.5, 0.866)

# lift3d.py
def lift_person(p: PersonPose, frame: Frame) -> dict[str, np.ndarray]   # 相機座標（x 右、y 下、z 前），公尺，key = JOINTS
def estimate_intrinsics(width: int, height: int, hfov_deg: float = 60.0) -> Intrinsics

# selector.py
def torso_center(joints_world: dict[str, np.ndarray]) -> np.ndarray     # 雙肩 + 雙髖平均
class PlayerSelector:
    def select(self, centers: list[np.ndarray], s: Settings) -> int | None   # 回傳候選 index
    def reset(self) -> None

# filter.py
class OneEuroFilter:
    def __init__(self, min_cutoff: float, beta: float, d_cutoff: float = 1.0): ...
    def __call__(self, x: np.ndarray, t: float) -> np.ndarray
class JointFilter:   # 每個關節一個 OneEuroFilter
    def __init__(self, min_cutoff: float, beta: float): ...
    def __call__(self, joints: dict[str, np.ndarray], t: float) -> dict[str, np.ndarray]
    def reset(self) -> None

# pipeline.py
class Detector(Protocol):
    def detect(self, rgb: np.ndarray, ts_ms: int) -> list[PersonPose]: ...
class Pipeline:
    def __init__(self, source: FrameSource, detector: Detector, get_settings: Callable[[], Settings]): ...
    def step(self) -> StepResult | None     # source.read() 回 None 就回 None（代表相機斷線或逾時）

# preview.py
def render_preview(r: StepResult, width: int = 480) -> dict   # 回傳 spec §4.5 的 {"type":"preview","jpeg_b64":...,"persons":[...]}
```

**行為要求（對照 spec §4.2–4.5）：**

- `lift_person` 有深度時：7×7 鄰域有效深度（>0）取中位數，用 `frame.intrinsics` 反投影。
  - 軀幹深度 = 雙肩、雙髖四點深度的中位數。
  - 關節深度無效，或與軀幹深度差 > 0.6 m 時：改用 `(MediaPipe 相對 xy 反投影, 軀幹深度 + (world[j].z − 軀幹 world z 平均))`。
- `lift_person` 無深度時：距離 `d = fx · 0.38 / 肩寬像素`。關節相機座標 = `world[j] − world 髖中點` 再平移到 `(0, 0, d)`。世界 landmark 的 y 已經是向下、z 遠離相機為正，跟相機座標同向，直接相加。
  - 無 intrinsics 時，用 `estimate_intrinsics(rgb 寬, 高)`。
- `PlayerSelector.select` 候選過濾：`depth_near_m ≤ c.z ≤ depth_far_m` 且 `|c.x − zone_center_x_m| ≤ zone_half_width_m`（c 為世界座標軀幹中心；z 就是離相機的水平距離）。
  - 黏著：上一次選中的中心與某合格候選距離 < 0.4 m，就選它。否則選 c.z 最小的。都不合格回 None，並清掉記憶。
- `Pipeline.step`：
  1. `source.read()`
  2. `detector.detect(frame.rgb, int(frame.ts*1000))`
  3. 對每個人 `lift_person` → `cam_to_world`
  4. `torso_center` → `select`
  5. 對選中者套 `JointFilter`。換人（選中 index 對應的中心跳 > 0.4 m）或 None 時 reset。
  6. 組 skeleton 訊息：`{"type":"skeleton","ts":frame.ts,"source":source.name,"has_depth":frame.depth_m is not None,"player":None | {"distance_m": 軀幹中心 z, "joints": {j: [x,y,z]}, "visibility": {...}}}`，數值是 Python float（可 JSON 化）。
  7. `persons`：每人 `{"bbox":[min u, min v, max u, max v],"selected":bool,"distance_m":float,"pixels":{j:[u,v]}}`。
- `render_preview`：把 rgb 縮到寬 `width`，畫每人骨架線（選中綠、其他灰）和 bbox，標距離文字；cv2 編 JPEG 品質 70，base64。`persons` 不含 `pixels`，bbox 依縮放比例換算。

**測試要寫的案例（每個都要有）：**

- tilt：pitch=0 → 只翻 y 加高度；pitch=30° 對上述檢查點；pitch=90° 時 (0,0,1) → (0, h−1, ~0)。
- lift3d：
  - 合成深度圖全為 2.0 m、intrinsics fx=fy=600、cx=320、cy=240：像素 (320,240) → (0,0,2)；(920,240) → (2,0,2)
  - 某關節深度為 0 時走 fallback，z ≈ 軀幹深度 ± 相對值
  - 無深度時：肩寬 114 px、fx=600 → d ≈ 2.0
- selector：兩人 z=2.0、z=1.8 都在範圍 → 選 1.8；z=1.2（太近）被排除；x 超出站位被排除；黏著：上一幀選 A（z=2.0），這幀 B（z=1.9）也合格 → 仍選 A；A 消失 → 選 B。
- filter：常數輸入 → 輸出等於輸入；階躍輸入 → 輸出單調趨近。
- pipeline：用 FakeSource（回固定 Frame，depth 全 2.0）和 FakeDetector（回兩個合成 PersonPose）→ `step()` 的 skeleton 選到較近者，joints 是世界座標（y 朝上，肩高於髖）；FakeSource 回 None → `step()` 回 None。
- preview：回傳 dict 的 `type == "preview"`，`jpeg_b64` 解碼後 cv2 讀得出寬 480 的圖。

- [ ] Step 1：先寫上述測試，跑 `uv run pytest tests/test_tilt.py tests/test_lift3d.py tests/test_selector.py tests/test_filter.py tests/test_pipeline.py tests/test_preview.py -q`，預期 FAIL（模組不存在）
- [ ] Step 2：依序實作 tilt → lift3d → selector → filter → pipeline → preview，每做完一個就跑它的測試
- [ ] Step 3：全部測試 PASS 後回報（不要 commit）

**Server 行為（spec §4.5–4.7）：**

- lifespan 開一條 daemon thread 跑 pipeline 迴圈：
  - `r = pipeline.step()`
  - `r` 是 None → 標記 camera disconnected
  - 否則把 `r.skeleton` 放進廣播；有 preview 訂閱者時，每 ≥100 ms 呼叫 `render_preview(r)` 廣播給訂閱者
  - 用 `asyncio.run_coroutine_threadsafe` 或 `loop.call_soon_threadsafe` 把訊息交給 event loop
- `status` 每秒廣播：camera ok / disconnected、近 1 秒實際 fps。
- `/ws`：
  - 連線時先送一次 `settings`
  - 收到 `{"type":"preview","on":bool}` 就切換該連線的訂閱
  - 送不出去的連線直接移除
  - 每個連線用自己的 asyncio.Queue（maxsize 4，滿了丟最舊的），避免慢 client 卡住
- REST：

**Retarget 數學（spec §5.2，在世界座標用數值計算）：**

- 軀幹：
  - `hipMid`、`shMid`；`Y = norm(shMid − hipMid)`
  - `L = left_shoulder − right_shoulder`；`X = norm(L − (L·Y)Y)`；`Z = X × Y`
  - 直立面向相機時，X=(1,0,0)、Y=(0,1,0)、Z=(0,0,1)
- `pitch = atan2(−Y.z, Y.y)`；`roll = asin(Y.x)`；`yaw = atan2(−L.z, L.x)`
  - rider：
    - `torsoPitch = clamp(UPRIGHT.torsoPitch + gain·pitch, 20°, 88°)`
    - `torsoRoll = clamp(roll, ±15°)`
    - `torsoYaw = clamp(yaw, ±20°)`
- 轉局部：`toLocal(v) = [v·X, v·Y, v·Z]`
- 頭：
  - `d = toLocal(nose − earMid)`
  - `relPitch = atan2(d.y, −d.z)`；`headPitch = clamp(relPitch + 30°, −40°, 70°)`
  - `headYaw = clamp(atan2(d.x, −d.z), ±30°)`
- 上臂：
  - `u = norm(toLocal(elbow − shoulder))`
  - 屈曲 `flex = atan2(−u.z, −u.y)`（0 = 下垂、90° = 前平舉），clamp [0°, 170°]
  - 外展 `abd = asin(±u.x)`（左手取 +u.x、右手取 −u.x，正 = 往外），clamp [−10°, 80°]
  - 以 flex、abd 重建單位向量
- 前臂：
  - `f = norm(toLocal(wrist − elbow))`
  - 與上臂夾角 > 150° 時，在兩向量平面上把 f 往 u 轉到剛好 150°
- visibility < 0.5：
  - 頭看 nose 和雙耳
  - 上臂看 shoulder、elbow
  - 前臂看 elbow、wrist
  - 軀幹看肩、髖：軀幹不可見時整個回傳 `UPRIGHT_POSE`

**Game 規則（spec §5.5）：**

- 任何狀態 `!cameraOk` → `MAINTENANCE`；`MAINTENANCE` 時 `cameraOk` → `ATTRACT`

- `COUNTDOWN`：滿 `countdown_s` → `RESULT`
