# 風阻姿勢大挑戰 v1.1：10 秒動態錄製

2026-10-16 · 修改自 `2026-10-15-aero-pose-v1-design.md`。本文沒提到的部分沿用 v1。

## 為什麼改

v1 實測時發現兩個問題：

1. 玩家一往前彎就被踢回「雙手舉過頭開始」。
   - 原因：選人器每一幀都重新檢查距離和站位。webcam 是用肩寬估距離，往前彎時肩膀在畫面上變大，估出來的距離小於 1.5 m，玩家就被剔除。
2. 使用者想要的玩法是「看見自己＋風被身體擋住的地方變紅」，錄 10 秒的動態姿勢，算平均省幾瓦；不是只定格一個姿勢。

## 流程（取代 v1 §5.5）

```
ATTRACT ──雙手舉高 start_hold_s(1 秒)──▶ COUNTDOWN(countdown_s=3) ──▶ RECORDING(record_s=10) ──▶ RESULT(result_s) ──▶ ATTRACT
COUNTDOWN / RECORDING 中，玩家連續消失 ≥ lost_timeout_s(3 秒) ──▶ ATTRACT（中止，不記成績）
任何狀態收到 camera=disconnected 或 WS 斷線 ──▶ MAINTENANCE；恢復後 ──▶ ATTRACT
```

| 狀態 | 畫面 |
| --- | --- |
| ATTRACT | 全螢幕相機畫面（鏡像）、右側今日排行榜（顯示平均瓦數）、大字「雙手舉高開始」；有玩家時顯示舉手進度圈。底部是免責文字。 |
| COUNTDOWN | 相機畫面，加上大字 3、2、1。風開始淡入。 |
| RECORDING | 相機畫面＋3D 透視風流＋紅色迎風面。頂部是即時「省 X 瓦」大字和剩餘秒數，底部是逐漸長出來的瓦數小曲線。 |
| RESULT | 左側是標準 3D 騎士重播這 10 秒的動作（循環）。右側是瓦數曲線，遊標和重播同步；另有大字平均瓦數、「比坐直平均少 X%」、名次「今日第 N 名 · 騎士 #K」、QR、解釋句和免責文字。 |

**畫面上不再有即時騎士**。騎士只在後台計分，結果頁重播時才第一次出現。

## 計分

- RECORDING 期間，每收到一個 skeleton 就做 retarget，再經 tracker（被遮擋時沿用上一個有效姿勢）得到 RiderPose。
  - 每個 pose 都存下來，給重播用。
- 每 `0.1 s` 取樣一次：把當下的 pose 套到後台的標準騎士（曲柄固定在 `FREEZE_CRANK_ANGLE`），算 `frontalArea`，換算 `watts = wattsSaved(baseline, area, settings)`。10 秒共 100 個樣本。
- 成績：
  - `meanWatts` = 樣本平均
  - `meanAreaM2` = 樣本面積平均
  - `pct = (baseline − meanArea) / baseline × 100`
  - `bestIndex` = 面積最小的樣本
- 送後端：`POST /api/results { area_m2: meanAreaM2, baseline_m2, watts_saved: meanWatts, png_b64 }`。後端依 `area_m2` 升冪排名，等同依平均瓦數降冪，後端 API 不變。

## 選人黏著（修 bug，取代 v1 §4.3 的黏著規則）

- 已鎖定玩家時：只要有候選人的軀幹中心與上一次距離 < 0.4 m，就沿用他，**不檢查距離範圍和站位區**。
- 只有在挑選新玩家時（沒有鎖定，或鎖定的人消失）才套用 `depth_near_m`、`depth_far_m` 和站位區。

## 相機畫面串流（新增 WS 訊息 `frame`）

- 每處理完一幀就推 `frame` 給**所有** client，上限 20 fps。
  - JPEG 寬 960，品質 70。
  - 選中玩家的分割 mask 縮到寬 192，閾值 0.5 → 0 或 255，每像素 1 byte。
- 型別見 `frontend/src/types.ts` 的 `FrameMsg`。影像和 mask 都是**相機原始方向**，由前端鏡像顯示。
- MediaPipe 開 `output_segmentation_masks=True`；`PersonPose.mask` 是該人的 mask，`StepResult.selected_mask` 是選中者的 mask。

## 風流與紅色迎風面（取代 v1 §5.6）

- 視覺：藍色光帶從觀眾這側（螢幕前方）往畫面深處吹，有透視感：近大遠小、往消失點收斂。
- 每條風帶在到達「玩家平面」時檢查落點：
  - 落在 mask 內（打到身體）：在那裡累積紅色熱度，風帶在身體邊緣散開、消失。
  - 沒打到：繼續往深處流走。
- 紅色熱度是一張與 mask 同解析度的浮點圖，每秒衰減到約 13%（半衰期約 0.33 s），模糊後以紅色半透明疊在相機畫面上。
  - 效果：身體正面持續發紅，趴低、縮小時紅色面積明顯變小。
- 只在 COUNTDOWN（淡入）和 RECORDING 顯示。

## 設定變更

- 新增 `record_s = 10`。
- 移除 `stillness_speed_mps`、`stillness_hold_s`、`posing_max_s`。舊 `settings.json` 的多餘欄位會被忽略。

## 不變

座標系、retarget、騎士幾何、面積光柵化、tracker、後端 REST、上傳、排行榜儲存、kiosk 啟動、MAINTENANCE、watchdog、wake lock，全部沿用 v1。
