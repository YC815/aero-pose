# 開攤前檢查清單（接上 Orbbec 後）

先照 `docs/orbbec.md` 跑 `aero doctor`，全部 PASS 後再往下做。

- [ ] **V1 左右方向**：站進站位，只舉**左手**。相機畫面裡**螢幕左邊**那隻手要舉起來（像照鏡子）；
  結果頁的 3D 騎士重播也是螢幕左邊那隻手舉起來。
  - 如果舉的是右邊那隻，代表 Orbbec 彩色畫面是鏡像的。
  - 修法：關掉 `OB_PROP_COLOR_MIRROR_BOOL`，或在 `pose.py` 翻轉 `u`。color 和 depth 要一起處理。
- [ ] **V2 內參**：doctor 第 5 項，寬 1280 時 fx 應約為 600（水平 FOV 約 90°）。
  - 看到 1100 左右，代表程式用的是 60° 的估計值，3D 座標會錯。
- [ ] **V3 前傾角**：面對相機分別前傾 0°、45°、75°，用 `aero record --source orbbec` 錄下來。
  - 比對騎士的軀幹角度和真人是否一致。
  - 在設定面板預覽裡看髖部有沒有被擋住。
- [ ] **V4 鏡頭俯仰**：找人站直錄一輪，錄製中的「省 X 瓦」要接近 0。
  - 差很多就調整 `camera_pitch_deg`。
- [ ] **紅色迎風面要對齊身體（鏡像正確）**：錄製中紅色要貼在身體上，舉左手時紅色跟著螢幕左邊的手走。
  - 紅色在身體的另一側（左右相反）或整片偏移，代表 mask 和相機畫面的鏡像不一致，不要開攤。
  - 蹲低、縮小時紅色面積要明顯變小。
- [ ] **V5 fps**：status 的 fps 要 ≥ 15。
  - 太低時，先試 `AERO_ORBBEC_COLOR=rgb`，或改用較低的 depth profile。
- [ ] **V6 螢幕不休眠**：放著不動 15 分鐘，確認螢幕還亮著。
- [ ] **V7 完整跑一輪**：待機 → 雙手舉高 → 倒數 3、2、1 → 錄製 10 秒 → 結果頁（騎士重播、曲線遊標同步、名次、QR）→ 回待機。
  - 用訪客實際會連的網路，拿手機掃一次 QR，確認成績卡的數字和結果頁一致。
  - 錄製中走出畫面超過 3 秒，要回到待機、不記成績。
- [ ] **瓦數破百的排版**：網址加 `?dev=1`，站在鏡頭前按空白鍵開始，10 秒全程趴到最低，確認結果頁的「省 X 瓦」和「少 X%」沒有擠爆、曲線沒有被擠扁。
  - 好成績很容易超過 100 W。
- [ ] **錄製 HUD 不擋臉**：站直時頭部不要被頂部的「省 X 瓦」底板蓋住。
- [ ] **攤位機事前準備**：
  - MediaPipe 模型要先下載到 `data/models/`，第一次下載也算在後端 30 秒的 watchdog 內。
  - webcam 模式要先手動給過一次相機權限。
